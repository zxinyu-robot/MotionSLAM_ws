## 5. 下一步验收

与规划工作包同一颗粒度（技能 / 翻译面）：

1. `ReturnHome`（1a-7 / SAFE-1）真机倒序返航。
2. `RecoverGlass`（1a-8 / SAFE-2）虚拟障碍真机。
3. OS4 度量侧重规划（1a-10）：执行中重规划、路径头可通行。
4. `ExploreFrontier`（1b）与 OS3 Token（1c / DEV-7）。
5. OS2 物模型信封（2-1b）边端联调：错包拒单；正包到达仍走 2-2 / DEV-6 / EDGE-CL。动态障碍随 Navigate 内核，不单开阶段。
6. OS 运行时 RT-1～RT-4（Skill Registry、闭环、记忆面、监控树）**不在本表勾选**，见规划 §6；未实现前不得记「通过」。
