## 2026-07-10 · Foxglove 地图看起来是斜的

### 现象

用户在 Foxglove 3D 面板中查看 `/grid_map/occupancy_inflate` 时反馈：**地图是斜的**。

### 真机采样（容器内，2026-07-10）

| 数据源 | roll | pitch | 说明 |
|--------|------|-------|------|
| `/lio/odom` | ≈ -2.7° | ≈ **14.6°** | Super-LIO |
| `/lio/robo/odom` | ≈ -2.7° | ≈ **14.6°** | `odom_robo` 全 0 |
| `/utlidar/robot_odom` | ≈ -2.3° | ≈ **2.3°** | Unitree 官方 |

| 话题 | 方法 | 结果 |
|------|------|------|
| `/lio/cloud_world` | 最低约 12% 点平面拟合 | 倾斜 ≈ **4.0°** |
| `/grid_map/occupancy_inflate` | 最低约 20% 体素拟合 | 倾斜 ≈ **1.0°** |

### 结论分级

| 陈述 | 状态 | 说明 |
|------|------|------|
| LIO odom 与 Unitree odom pitch 差约 12° | **已证实** | 见上表采样 |
| `odom_robo` 当前为全 0 | **已证实** | 配置文件 |
| 差异全部来自外参未标定 | **假设** | 亦可能含安装角/IMU 初始化/坐标语义 |
| 代价图未大角度建歪 | **假设** | 单次粗糙拟合，无地面真值 |
| Fixed Frame 误选导致观感倾斜 | **假设** | 未记录用户当时 Fixed Frame |
| 导航链路不受影响 | **待验证** | 无 E2E；见 F/H 系列验收 |
| `level_orientation` 后 pose 仅 yaw | **修改结果** | 非导航正确性验收 |

### 处理措施（可视化层）

- Foxglove: Fixed Frame=`world`, Top 视角
- `robot_pose_viz`: `level_orientation:=true`

### 待办

- [x] T2.5: `scripts/verify/calibrate_odom_robo.py` 或 `scripts/calibrate_odom_robo.py` + 迭代 `odom_robo` → pitch=11.8°, 差 0.43°
- [x] Nav2 N4/N5 **不再**填入当前主链测试记录（该文件已声明不收 Nav2）

## 2026-07-13 · T2.5 odom_robo 外参标定

### 真机采样（站立静止，pitch=11.8°）

| 数据源 | roll | pitch | yaw |
|--------|------|-------|-----|
| `/lio/robo/odom` | -0.33° | **0.56°** | -0.17° |
| `/utlidar/robot_odom` | 0.18° | **0.14°** | -115.08° |

**pitch 差 (LIO − Unitree): 0.43°** — F1 通过标准 < 3°。

### 标定过程摘要

| 阶段 | odom_robo pitch | pitch 差 |

| 初值全 0 | 0 | 11.81° |
| 误设 -11.8（符号反） | -11.8 | 23.57° |

NOTE: Super-LIO 中 yaml pitch **增大** → `/lio/robo/odom` pitch **减小**；脚本按「当前值 + dp」迭代。
