## 1. 项目结构

见 [readme.md](../../readme.md) §目录。核心包：

- `motionslam_bringup` — launch、BT、ingress、frontier、返航
- `motionslam_pipeline` — `pct_resident_planner`、forwarder、lifecycle、`virtual_obstacle_merge`、`bev_glass_layer`
- `scan_planner` — SCAN + closed_loop（`scan_planner_ws` overlay）
- 上游 `pct_planner` — Python/Open3D 对照（独立 ws，日常不启）

## 2. TDD 模块（摘要）

| 模块 | 输入 | 输出 | 关键约束 |
|------|------|------|----------|
| CmdVelForwarder | `/motion/command` | Sport API | 看门狗、限幅 |
| pct_resident_planner | Super-LIO cloud/odom（launch remap） | `/global_path` | stamp 回写请求；不直写执行路径 |
| demo_scan_bt_orchestrator | 航点 / frontier / ingress | `/goal_pose`、`/initial_path`、mission/event | 唯一执行写口；拒空/伪短路径 |
| return_home | 面包屑 + uplink/玻璃/显式 | `/initial_path` | 不调 PCT A* |
| virtual_obstacle_merge | lidar + 虚拟障碍 | `/perception/scan_cloud_fused` | 玻璃默认开 |
| bev_glass_layer | `/semantic/bev_grid_world` | `/perception/virtual_obstacles_bev` | 无 engine 不 stub 推理 |
| semantic_token_uplink | BEV grid | TCP :9876 | 随 `with_semantic_bev` |
| command_executor | ActionGroup / `thing_envelope.v1` | BT semantic | 需 `with_edge_uplink` + `with_semantic_objnav` |
| 边侧 Qwen2.5-VL | RGB :9878 + 子图 :9877 | `thing_envelope.v1` → :9879 | 见 [边侧Qwen2.5-VL接入说明.md](边侧Qwen2.5-VL接入说明.md) |

`rgb_bev_node.py` 仍在源树，**默认 launch 不启动**。整机 E2E：见 [测试记录.md](../测试验收/测试记录.md)。

## 4. 构建

```bash
./scripts/motionslam build
source /ws/scripts/dev/source_ws_env.sh
# SCAN overlay
cd /ws/scan_planner_ws && colcon build --symlink-install

# 仅 Python PCT 对照
./scripts/dev/build_pct_planner.sh
```

日常开栈走 C++ `pct_resident_planner`，不经 `pct_demo_bridge`，也不要求 `pct_planner_ws`。
