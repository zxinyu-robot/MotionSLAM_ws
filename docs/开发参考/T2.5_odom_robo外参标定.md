## 1. 标定目的

Super-LIO 发布的 `/lio/robo/odom` 表示 **机器人机体** 在 world 下的位姿。参数 `lio.extrinsic.odom_robo` 描述 **IMU/LIO 坐标系 → 机体坐标系** 的外参。未标定时 LIO pitch 与 Unitree 官方 `/utlidar/robot_odom` 可差 **~12°**，影响 Foxglove 观感及后续导航对齐。

**F1 通过标准**：两路 odom 的 **pitch 差 < 3°**（静止、站立工况）。

## 3. ROS 话题


| 话题                    | 类型                  | 用途                        |
| --------------------- | ------------------- | ------------------------- |
| `/lio/robo/odom`      | `nav_msgs/Odometry` | Super-LIO 机体位姿（**标定对象**）  |
| `/lio/odom`           | `nav_msgs/Odometry` | IMU 帧位姿（脚本 fallback）      |
| `/utlidar/robot_odom` | `nav_msgs/Odometry` | Unitree 官方机体里程计（**参考真值**） |


**不用于 pitch 标定**：两路 odom 的 **yaw 差**（world 零点不同，可差 90°+）。

## 4. 测试步骤



### 前置

1. 容器内 Super-LIO 栈已启动（如 `mapping.launch.py` / `slam_viz.launch.py` / `ego_nav.launch.py`）
2. 狗 **正常站立、平地、静止** 5–10 s（勿趴下、勿行走）
3. 修改 yaml 后 **必须重启 LIO** 才生效



### 执行

```bash
# 容器内 /ws
python3 scripts/calibrate_odom_robo.py --once
```



### 判定


| 输出                                            | 含义               |
| --------------------------------------------- | ---------------- |
| `OK: pitch 差 < 3° (F1 通过)`                    | 验收通过             |
| `建议: odom_robo pitch 在 yaml 当前值上 **加** X deg` | 未通过，改 yaml 后重启复测 |


自动化：

```bash
./scripts/e2e_verify.sh   # 含 F1b --report-only
```

## 6. 复测与回归

- 更换 mid360 安装位姿、更换狗型号、IMU 大振动后应 **重跑 F1**
- F2（静止漂移 / 直线回测）仍 **待复测**，外参正确不等于定位精度已验收
- Foxglove「地图斜」：外参标定后应改善 `/lio/robo/odom` 姿态；代价图倾斜另见 [Foxglove代价图可视化](Foxglove代价图可视化.md)
